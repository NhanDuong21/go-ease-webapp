Nguyên nhân: exports dùng dist nhưng root chỉ build một lần.

Sau sửa, root build thành công trước khi chạy một contracts watcher, API và Vite. Probe làm API trả service mới; Chrome nhận guard mới và báo “Phản hồi API chưa đúng định dạng health.” sau request mới, không restart toàn bộ dev. Không cần đổi Vite config vì workspace ESM đã được HMR đúng. Probe lỗi `string = 42` hiện TS2322; `noEmitOnError` giữ dist hợp lệ, API tiếp tục phục vụ bản đó. Khôi phục source byte-exact → watcher build lại, API service bình thường, web retry success. API có thể restart ngắn khi compile; health card chỉ cập nhật khi gửi request mới.

Ctrl+C ở bản cũ đóng cổng nhưng còn hai tiến trình concurrently. Bật `--raw` để các tiến trình dùng console kế thừa: thử lại `pnpm dev` trên PowerShell, ghi nhận toàn bộ 18 PID của cây concurrently/watcher/app trước Ctrl+C; sau đó còn 0 PID và 0 cổng listen. Regression tự động Linux gửi SIGINT đến process group và kiểm tra PID con/cổng đã dừng; Windows regression dùng taskkill để dọn tree, không thay thế bằng chứng Ctrl+C trực tiếp.
